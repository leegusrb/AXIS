## 측정 조건

2026-11-27, Apple M1 노트북, 다른 작업이 함께 돌아 load average가 약 30인 상태에서 쟀다. 그래서 값의 편차가 크다(같은 명령을 조용할 때 돌린 첫 측정에서는 yolo11n-pose 320이 23ms, 깊이 256이 52ms). 발표용 숫자는 다른 프로그램을 끄고 다시 잰다.

```
SSL_CERT_FILE=$(.venv/bin/python -m certifi) .venv/bin/python -m axis_ai.eval.speed --model models/v4 --image <사진.jpg> --out docs/results/<날짜>-v4-speed.md
```

실시간 서버 한 프레임(디코드+검출+안내) 실측은 깊이 끔 평균 72ms, 깊이 켬 평균 127ms다(Task 7 커밋 기록).
